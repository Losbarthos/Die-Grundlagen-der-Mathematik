Kapitel 1

Einleitung

Dieser Band behandelt partielle, totale und wohlgeordnete Relationsoperato-
ren unabhängig von einem besonderen Zahlbereich. Minimum, Maximum,
Schranken, Infimum und Supremum werden hier als allgemeine Ordnungsbe-
griffe entwickelt. Natürliche Ordnungen und halbverbandsinduzierte Ordnun-
gen erscheinen anschließend als Anwendungen in den jeweiligen Fachbänden.

2.1     Begriff der Ordnung
2.1.1   Axiome einer partiellen Ordnung

Axiom 11.2.1.1 (Antisymmetrie).

Mengen:                   A, x, y
Relationsoperatoren:      ≤

                           x ≤ y, y ≤ x ` x = y

2.1.2   Definition der partiellen Ordnung

Definition 11.2.1.1 (Begriff der partiellen Ordnung).

Mengen:                           A, x, y, z
Relationsoperatoren:              ≤
Axiome:
Binärer Relationsoperator:        ≤ auf A
Reflexivität:                     x∈A`x≤x                 Ax. 10.2.1.1
Transitivität:                    x ≤ y, y ≤ z ` x ≤ z    Ax. 10.2.1.3
Antisymmetrie:                    x ≤ y, y ≤ x ` x = y    Ax. 11.2.1.1
Neue Symbole:
Partielle Ordnung:                . PartOrd(A, ≤)

                               PartOrd(A, ≤)
    Die Ordnung wird somit stets zusammen mit ihrem Träger angegeben.
Ihre Auswertung erfolgt in Infixnotation: x ≤ y, nicht durch die Zugehörigkeit
eines geordneten Paares zu einer Relationsmenge.

2.1.6    Extremale Elemente
Minimales Element und Minimum
Ein minimales Element besitzt in der Teilmenge kein echt kleineres Element.
Ein Minimum ist demgegenüber ein kleinstes Element und liegt unter jedem
Element der Teilmenge. Die folgenden Sätze halten den genauen Zusammen-
hang fest.

Definition 11.2.1.4 (Minimales Element einer Teilmenge).

Mengen:                    A, T, m, x
Relationsoperatoren:       ≤
Partielle Ordnung:         . PartOrd(A, ≤)
Teilmenge:                 T ⊆A
Neues Symbol:
Minimales Element:         . MinElA,≤ (m, T )


        T ⊆ A ` MinElA,≤ (m, T ) := m ∈ T ∧ ∀x ∈ T (x ≤ m → x = m)

Die Bandnummern geben die Beweisabhängigkeit wieder; sie schließen fach-
