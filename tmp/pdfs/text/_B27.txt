2.1   Definition der Linkskürzbarkeit

Definition 27.2.1.1 (Linkskürzbare Operation).

Mengen:              A, a, b, c
Linkskürzung:        a, b, c ∈ A, a ? b = a ? c ` b = c
Neues Symbol:
Linkskürzbarkeit:    . LKürz(A, ?)

                                LKürz(A, ?)

Mengen:   A, a, b, c

              LKürz(A, ?) , a, b, c ∈ A, a ? b = a ? c ` b = c
