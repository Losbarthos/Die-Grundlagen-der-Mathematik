# Contributing / Mitwirkung

Thank you for taking the time to examine the project. Focused corrections are
especially valuable while the manuscript is still evolving.

Vielen Dank für die Beschäftigung mit dem Projekt. Konkrete Korrekturen sind
besonders wertvoll, solange das Manuskript noch weiterentwickelt wird.

## Good issue reports / Hilfreiche Issues

Please include as much of the following as possible:

- volume and PDF page;
- theorem, definition, axiom, or section number;
- the exact formula or proof line concerned;
- why it appears incorrect, incomplete, or unclear;
- a counterexample, reference, or suggested correction when available.

Geeignete Themen sind insbesondere:

- mathematische Fehler oder nicht genannte Voraussetzungen;
- fehlerhafte oder zirkuläre Satzverweise;
- unklare Notation und sprachliche Fehler;
- kürzere oder transparentere Beweise;
- Literaturhinweise und verwandte Arbeiten;
- reproduzierbare Build- oder PDF-Probleme.

German and English reports are both welcome. For discussion, please
[open a GitHub issue](https://github.com/Losbarthos/Die-Grundlagen-der-Mathematik/issues/new).

## Pull requests

Please open an issue before a substantial pull request so that scope,
notation, and dependency placement can be agreed first. Keep unrelated changes
separate, preserve the existing volume dependency order, and describe how the
affected standalone volume was built and checked.

For a mathematical change, explain the mathematical reason in the pull request
description; a successful LaTeX build alone is not evidence of correctness.
